# metro_expansion

Code and manuscript for a matched-budget comparison of graph reinforcement learning and evolutionary multi-objective search for metro line extension on the public Xi'an and Amsterdam benchmark grids, with fairness-aware scoring, a leave-one-line-out test and a cross-city warm-start study.

## Layout

- `src/envs/` -- fast gather-based environment, verified equal to the upstream environment (`tests/test_fast_env.py`); city variants (`xian`, `amsterdam`, line-removed variants); scoring context.
- `src/eval/` -- objectives (demand share, generalised Gini welfare, newly reached trip-end mass), scaling and Tchebycheff scalarisation, hypervolume / expected utility / IGD+, statistics, holdout metrics, run records.
- `src/gnn/`, `src/rl/` -- graph encoder, weight-conditioned policy with start head and lookahead features, batched REINFORCE with a leave-one-out baseline.
- `src/baselines/` -- NSGA-II, scalarised genetic algorithms, greedy, random lines, wrappers around the upstream tabular Q-learning and genetic algorithm.
- `scripts/` -- `compute_normalization.py` (objective anchors), `run_rl.py`, `run_evo.py`, `run_tabular.py`, `run_jobs.py` (parallel, resumable job runner), `make_city_variants.py`.
- `results/` -- normalisation anchors, tuning runs and run records (`mnep.run.v1` JSON).
- `docs/analysis_plan.md` -- endpoints, tuning protocol and claim rules, fixed before any evaluation run.
- `docs/design/` -- early project design notes. `docs/baseline_reproduction.md`, `docs/data_sources.md` -- baseline reproduction notes and data provenance.
- `manuscript/` -- LaTeX source of the paper (`main.tex`, Elsevier `elsarticle`), cover letter, highlights (`submission/highlights.txt`) and generated tables and numbers (`generated/`). Build: `pdflatex main.tex && bibtex main && pdflatex main.tex && pdflatex main.tex`. Regenerate the tables with `scripts/aggregate.py`, `scripts/make_tables.py`, `scripts/holdout_macros.py`, `scripts/transfer_macros.py` and `scripts/ablation_macros.py`.
- `legacy` scripts (`scripts/train_xian.py`, `scripts/train_hcmc.py`, ...) -- the original single-episode REINFORCE trainers, kept for reproducibility of the earlier configuration.

## Environment

Python 3.13 with CPU PyTorch. See `requirements.txt` (CUDA pins can be replaced by the CPU build).

```
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install torch-geometric mo-gymnasium gymnasium numpy pandas scikit-learn networkx scipy pytest geopandas shapely
git clone --depth 1 --recurse-submodules https://github.com/dimichai/tabular-tndp external/tabular-tndp
git clone --depth 1 https://github.com/CityScope/CSL_HCMC external/CSL_HCMC   # only for the legacy Ho Chi Minh City scripts
pytest tests/ -q
```

The upstream repositories under `external/` are not redistributed. `data/cities/` is generated by `scripts/make_city_variants.py`.

## Reproducing the experiments

```
python3.13 scripts/compute_normalization.py --city xian --variant full --groups price_groups_5.txt \
    --seeds 100 101 102 --nr_stations 20 --chained 1 --out results/xian_full/normalization.json
python3.13 scripts/run_rl.py   --city xian --seed 0 --norm results/xian_full/normalization.json --out results/xian_full/rl_full/seed0.json
python3.13 scripts/run_evo.py  --city xian --algo nsga2 --seed 0 --norm results/xian_full/normalization.json --out results/xian_full/nsga2/seed0.json
python3.13 scripts/run_jobs.py jobs.txt --parallel 4     # runs a file of commands, skips finished outputs
```

Evaluation seeds are 0-9; seeds 100-102 are reserved for anchors and tuning.

## Scope note

The method's action space and object of design are rail transit only. Where a city's existing rail network is too sparse to define a well-posed expansion problem, the bus network can serve as an auxiliary input signal but is never designed or evaluated. See `docs/design/2026-08-18-metro-expansion-manuscript-design.md`.
