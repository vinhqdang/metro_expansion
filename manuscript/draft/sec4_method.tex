\section{Methods}\label{sec:method}

\subsection{Graph policy}\label{sec:policy}
\paragraph{Encoder} Each cell has a seven-dimensional input: a one-hot price group, an indicator for cells on an existing line, and the normalised log OD degree. Two edge types connect the cells: spatial edges between the eight grid neighbours, and OD edges weighted by flow. Two message-passing layers aggregate each relation separately, combine the results with a residual connection and a $\tanh$ non-linearity, and produce 32-dimensional embeddings $\mathbf h_i$. The cell features do not depend on the line being built, so the embeddings are computed once per update and shared by all episodes in a batch.

\paragraph{Move policy} At each step the policy scores the eight candidate cells. The key of candidate $c$ is $\mathbf k_c=\mathbf W_k[\mathbf h_c\,\|\,\boldsymbol\phi_c]$, where $\boldsymbol\phi_c$ holds one-step lookahead features: the log of the OD flow the move would add, the exact gain it would give each group, the trip-end mass it would newly bring within reach, a flag for cells adjacent to an existing line, and the fraction of the station budget left. The gain features are the environment's own one-step reward, computed without moving the agent. The query is
\begin{equation}
\mathbf q=\mathbf W_q\big(\operatorname{pool}(\mathbf h,V)+\mathbf W_e\mathbf w+\mathbf W_s\bar{\mathbf s}\big),
\end{equation}
where $\operatorname{pool}$ averages the embeddings of the cells already on the line $V$, $\mathbf w$ is the weight vector of the episode, and $\bar{\mathbf s}$ is the group-share vector achieved so far. Infeasible moves are masked and the move distribution is a softmax of $\mathbf k_c^{\top}\mathbf q/\sqrt d$. Giving the policy $\mathbf w$ is what lets one trained model answer any trade-off.

\paragraph{Start policy} A second head scores all $N$ cells as start cells, with $\mathbf W_{ks}\mathbf h_i$ as keys and $\mathbf W_{qs}(\bar{\mathbf h}+\mathbf W_e\mathbf w)$ as query. The tabular and genetic baselines also choose their start, so this removes a handicap that a random start would impose on the policy.

\subsection{Training}\label{sec:training}
We train with REINFORCE \citep{williams1992} and a leave-one-out baseline \citep{kool2019}. An episode builds one line and ends after $T$ stations or when no move is allowed. Its return is the terminal scalarised objective, $R=-g(\tilde{\mathbf f}(L)\mid\mathbf w)$, with no discounting because the horizon is short and fixed. One update uses $B=16$ on-policy episodes: $M=4$ weight vectors drawn from a Dirichlet$(1,1,1)$ distribution and $K=4$ rollouts per weight vector. The advantage of rollout $k$ for weight vector $m$ is
\begin{equation}
A^{m,k}=R^{m,k}-\frac{1}{K-1}\sum_{k'\ne k}R^{m,k'} .
\end{equation}
The baseline does not depend on the rollout's own actions, so the gradient stays unbiased. The loss is the advantage-weighted sum of log-probabilities of all decisions in the episode, including the start cell, minus an entropy bonus whose weight decays linearly to zero over the first 70\% of updates. We use Adam with a cosine learning-rate schedule and gradient clipping over all parameters. There is no replay buffer, no value network and no temporal-difference bootstrapping: every update uses Monte Carlo returns of episodes generated by the current policy, which are then discarded.

\begin{algorithm}[t]
\caption{Weight-conditioned REINFORCE with a leave-one-out baseline}\label{alg:train}
\begin{algorithmic}[1]
\Require city graph, anchors $f^{\mathrm{ref}}$, number of updates $U$, $M=4$, $K=4$
\State initialise parameters $\theta$
\For{$u=1,\dots,U$}
  \State $\mathbf H\gets$ Encoder$_\theta$(graph) \Comment{once per update}
  \For{$m=1,\dots,M$}
    \State draw $\mathbf w_m\sim\mathrm{Dir}(1,1,1)$
    \For{$k=1,\dots,K$}
      \State sample a start cell, then moves, from $\pi_\theta(\cdot\mid\mathbf H,\mathbf w_m)$
      \State record $\sum_t\log\pi_\theta$, entropy and the line's objectives
      \State $R^{m,k}\gets-g(\tilde{\mathbf f}\mid\mathbf w_m)$
    \EndFor
    \State $A^{m,k}\gets R^{m,k}-\operatorname{mean}_{k'\ne k}R^{m,k'}$ for all $k$
  \EndFor
  \State $\theta\gets$ Adam step on $-\tfrac1{MK}\sum A^{m,k}\sum_t\log\pi_\theta-\beta_u\bar{\mathcal H}$
\EndFor
\end{algorithmic}
\end{algorithm}

\subsection{Baselines}\label{sec:baselines}
All baselines use the same environment, objectives, scaling and start-cell freedom. Evolutionary methods share one genome: a start cell followed by a move index for each later station, repaired to the nearest feasible move.
\begin{description}
\item[NSGA-II] \citep{deb2002}: population 50, 201 generations, 50 offspring per generation, so $50+201\times 50=10\,100$ evaluated lines, objectives $(\tilde f_1,\tilde f_2,\tilde f_3)$. For each weight vector the deployed solution is the member of the final population with the smallest $g$.
\item[Scalarised GA]: the same operators with fitness $-g(\tilde{\mathbf f}\mid\mathbf w)$, run separately for each of the 15 weight vectors. We report a matched variant (population 30, 21 generations per weight, 9\,900 lines in total) and a full-budget variant (10\,100 lines per weight, fifteen times more computation).
\item[GA and tabular Q-learning of \citet{michailidis2026}]: their public code, unmodified, optimising demand or their two-group generalised Gini reward on our environment. Q-learning runs 10\,000 episodes. The genetic algorithm uses their default population 100 and 50 generations; about 41\% of its offspring are infeasible and are dropped, so it completes about 5\,100 lines.
\item[Greedy]: from every start cell, repeatedly take the feasible move that most reduces $g$. It uses no learning and shows what one-step lookahead alone achieves.
\item[Random search]: 10\,100 random feasible lines from random start cells. The deployable line for each weight vector is the one with the smallest $g$ among all of them.
\end{description}
Methods that return a single policy-independent line (tabular Q-learning, greedy per weight) are marked as such in the tables. For every method we also keep an archive of all lines it evaluated and report the Pareto set of that archive separately from the deployable set.
